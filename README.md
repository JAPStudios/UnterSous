# UnterSous

This repository contains the initial Expo / React Native mobile project for UnterSous.

The current application is only a branded entry point. It does not yet implement passenger or driver workflows, transportation or delivery requests, licensing support, dispatch, payments or production services.

## Development

Requirements: Node.js and npm.

```sh
npm install
npm run typecheck
npm test
npx expo start
```

## Product context

The available project context describes UnterSous as a not-for-profit competitor in transportation and delivery. It includes paid driving opportunities, assistance with pursuing driving licences when legally eligible, free qualifying medical and legal rides for passengers, and driver compensation paid directly by UnterSous.

Those high-level statements are not a complete implementation specification. Previously added screens, service-category models, request forms and driver application drafts were not validated requirements and have been removed.
