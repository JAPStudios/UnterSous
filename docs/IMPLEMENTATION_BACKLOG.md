## Verification and release

- [ ] Automated unit and integration tests.
- [ ] Authorization and sensitive-data access tests.
- [ ] Accessibility review.
- [ ] Security review and dependency audit.
- [ ] Operational readiness and emergency procedures.
- [ ] Staging deployment and acceptance testing.
- [ ] Production deployment only after legal, insurance and operational approvals.

## Definition of done

A backlog item is complete only after implementation, automated tests, review and verification in the intended environment. Documentation alone does not complete an application feature.
